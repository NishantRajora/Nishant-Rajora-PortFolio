# Nishant Rajora Portfolio

Personal portfolio website for Nishant Rajora, a Data Science undergraduate focused on artificial intelligence, machine learning, data engineering, business intelligence, and software systems.

## Live Website

[View the portfolio](https://nishantrajora.github.io/Nishant-Rajora-PortFolio/)

## About the Website

The portfolio presents Nishant's work, technical skills, research interests, and contact details through a responsive single-page experience. It includes:

- Featured machine learning, generative AI, cybersecurity, business intelligence, and software projects
- About section with education, location, and areas of focus
- Skills and technologies grouped by category
- Contact details and links to professional and coding profiles
- Responsive navigation with a mobile menu
- Scroll reveal animations, animated statistics, and a canvas grid background

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
- Google Fonts

## Project Structure

```text
.
├── index.html    # Main portfolio page
├── style.css     # Layout, styling, responsive design, and animations
├── script.js     # Navigation, animations, counters, and interactive behavior
└── profile.png   # Profile image used in the hero section
```

## Run Locally

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.

For a local development server, use any static file server. For example, with Python:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
